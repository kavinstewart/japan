# Tokyo Crew '26

Trip site for our Japan trip, Oct 17–27, 2026. It's one self-contained `index.html`, narrated by Mochi, a lucky cat built in three.js.

Sections: the day-by-day plan, Zauo (the catch-your-own-dinner restaurant), a 15-minute walking map around Mimaru Suites Asakusa, the Pokémon Center mission, surprise ideas, and know-how.

Hosting: GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
